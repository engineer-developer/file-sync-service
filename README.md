# Сервис синхронизации файлов 

## О сервисе
Сервис осуществляет синхронизацию файлов на компьютере пользователя и в облачном хранилище файлов.

### Основные функции приложения:
* связывание указанной папки на локальном компьютере и в облачном хранилище;
* отслеживание изменений в файлах на локальном компьютере и внесение изменений в облачном хранилище.
* в качестве облачного хранилища использован [Яндекс Диск](https://yandex.ru/dev/disk-api/doc/ru/)

### Логика синхронизации
* Приложение с заданной периодичностью изучает файлы в отслеживаемой папке.
* Подразумевается, что в отслеживаемой папке будут появляться только новые файлы, но не новые папки.
* При появлении нового локального файла он загружается в облачное хранилище.
* При изменении локального файла его новая версия загружается в облачное хранилище.
* При удалении локального файла он удаляется из облачного хранилища.
* В файл лога записываются результаты синхронизации.

## Настройка параметров работы сервиса 
### Зависимости приложения

* [python](https://www.python.org/) >=3.12,<4.0
* [poetry](https://python-poetry.org/docs/#installation) >=2.0.0,<3.0.0

#### Установка остальных зависимостей

Необходимо создать [виртуальное окружение](https://docs.python.org/3/library/venv.html#module-venv) и активировать его. \
Выполнить установку зависимостей с помощью poetry командой
```
poetry install
```

### Подготовка переменных окружения
В папке src/app находится файл .env.example, который необходимо переименовать в .env

#### В файле .env нужно задать:
* путь к синхронизируемой папке,
* имя папки в облачном хранилище,
* [токен доступа](https://yandex.ru/dev/id/doc/ru/access) к облачному хранилищу,
* период синхронизации в секундах,
* путь к файлу лога.

## Запуск приложения
В корне проекта выполните команду 
```
poetry run python src/app/loader.py
```
